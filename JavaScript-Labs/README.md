## Mục tiêu
Thực hành nền tảng JavaScript, thao tác DOM, xử lý sự kiện và sử dụng jQuery để xây dựng các trang web có tính tương tác.

## Nội dung thực hành
- **Lab 08 – JavaScript 1: Language Foundations:** Exercise 8.1–8.11; nhúng JavaScript, console, built-in objects, arrays, functions và objects.
- **Lab 09 – JavaScript 2: DOM and Events:** Exercise 9.1–9.8; DOM selection, DOM tree, tạo/xóa phần tử, event listeners, load event, debugging và form validation.
- **Lab 10 – JavaScript 3: jQuery:** Exercise 10.1–10.10; jQuery setup, selectors, events, DOM insertion, effects, animations, GET requests và jqXHR.

## Cách chạy
1. Tải hoặc clone repository về máy.
2. Mở thư mục `JavaScript-Labs`.
3. Mở `index.html` bằng trình duyệt để xem portfolio.
4. Mở từng thư mục Lab và chạy các file HTML tương ứng.
5. Lab 10 sử dụng bản jQuery cục bộ trong `Lab10/js/jquery-3.1.1.min.js`; hai bài GET cần kết nối Internet và dịch vụ bên ngoài còn hoạt động.
